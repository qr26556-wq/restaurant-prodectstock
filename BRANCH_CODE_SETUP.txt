BRANCH CODE SYSTEM

1. Owner activates Multi-Branch 30 Days or Lifetime.
2. Settings -> Multi-Branch Cloud -> Add branch.
3. A reusable Branch Code is generated automatically (example BR-7K3PXMAB).
4. Copy that code and use it on each phone/computer that should work in that branch.
5. On a new device: Login -> Join a branch code -> enter Branch Code -> Continue with Google.
6. The device is assigned cashier access to that branch and the same Branch Code can be used on multiple devices.
7. Branch Code is NOT the paid Activation Code. Activation Code activates the plan; Branch Code connects a device/user to a branch.
8. Branch staff cannot switch to another branch. The owner/admin can switch branches.
9. All branch Products/Stock/Orders/Sales/Customers/Tables are stored under that branch's restaurant document.
10. Deploy firestore.rules before testing.

PLAN CODES

- Multi-branch Lifetime: multibranch_lifetime, no expiry.
